# Laptop Market Analysis Dashboard | Excel

## Project Overview
An interactive Excel dashboard developed to analyse laptop market data, explore brand distribution, compare pricing, and identify trends across RAM, CPU, GPU, and operating systems.

The project uses Microsoft Excel features such as PivotTables, PivotCharts, slicers, and KPI cards to transform raw laptop data into meaningful business insights.

## Project Objectives
- Analyse laptop distribution across different brands.
- Compare average laptop prices by brand.
- Understand RAM configuration preferences.
- Examine CPU and GPU brand distribution.
- Explore the relationship between RAM capacity and laptop pricing.
- Build an interactive dashboard for business analysis.

## Tools & Technologies
- Microsoft Excel
- PivotTables
- PivotCharts
- Excel Slicers
- Data Cleaning
- KPI Cards
- Data Visualization

## Dashboard Features
- Interactive brand, CPU brand, GPU brand, and operating system slicers.
- KPI cards for key performance indicators.
- Six analytical charts.
- Business insights based on the dataset.
- Interactive filtering for exploring laptop market trends.

## Key Business Insights
1. **Brand Distribution:** Lenovo has the highest number of laptop models in the dataset.
2. **Premium Pricing:** Alienware records the highest average laptop price among the brands analysed.
3. **RAM Configuration:** 16 GB RAM is the most prevalent configuration.
4. **Processor Distribution:** Intel has the highest representation among CPU brands.
5. **GPU Distribution:** Apple is the most represented GPU brand in the dataset.
6. **RAM and Pricing Trend:** Average laptop prices generally increase with RAM capacity, reaching their highest level at 64 GB RAM.

## Dataset
- Total laptop records analysed: 992
- Data fields include brand, price, RAM, CPU, GPU, operating system, and other laptop specifications.
- Missing GPU brand information was labelled as "Not Specified" for analysis.
