### 1. ☕ Coffee Sales Dashboard

An interactive Excel dashboard designed to analyze coffee sales performance and explore sales patterns across different dimensions.

**Key Features**

* Sales performance analysis
* Monthly sales trends
* Analysis by store location
* Hourly sales distribution
* Interactive slicers and PivotCharts
* KPI-based reporting

**Technologies:** Microsoft Excel, Power Query, PivotTables, PivotCharts, Slicers, Excel Formulas

**Project Files:** [View Coffee Sales Dashboard](Coffee-Sales-Dashboard/)

---

### 2. 💻 Laptop Market Analysis Dashboard

An interactive Excel dashboard analyzing **992 laptop records** to explore brand distribution, pricing patterns, and hardware specifications.

**Key Features**

* Laptop count by brand
* Average price comparison across brands
* RAM configuration analysis
* CPU and GPU brand distribution
* RAM capacity versus average pricing
* Interactive KPI cards, charts, and slicers

**Technologies:** Microsoft Excel, PivotTables, PivotCharts, Slicers, Data Cleaning

**Project Files:** [View Laptop Market Analysis](Laptop-Market-Analysis/)
