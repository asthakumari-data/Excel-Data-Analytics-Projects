# ☕ Coffee Sales Dashboard — Excel Data Analysis Project

An interactive **Coffee Sales Dashboard** built in **Microsoft Excel** to analyze sales performance, identify customer purchasing patterns, and generate actionable business insights.

The project demonstrates an end-to-end data analysis workflow including **data cleaning, transformation, PivotTables, interactive slicers, KPI analysis, visualization, and business insights**.

---

## 📊 Project Overview

This project analyzes coffee shop transaction data to understand:

* Overall sales performance
* Monthly sales trends
* Sales by store location
* Customer purchasing patterns by hour
* Product size distribution
* Peak sales periods
* Key business insights from transaction data

The final dashboard provides an interactive view of the dataset, allowing users to explore the analysis using slicers and quickly identify important sales patterns.

---

## 🎯 Objectives

The main objectives of this project are to:

* Clean and prepare raw coffee sales data
* Transform the dataset using **Power Query**
* Analyze sales performance using **PivotTables**
* Identify monthly sales trends
* Analyze sales across different store locations
* Identify peak purchasing hours
* Understand product size distribution
* Build an interactive Excel dashboard
* Extract meaningful business insights from the data

## 🧹 Data Cleaning & Transformation

The dataset was prepared and transformed using **Power Query** before creating the dashboard.

Key data preparation steps included:

* Handling data type issues
* Cleaning transaction data
* Transforming date and time information
* Extracting useful time-based information
* Creating an **Hour** field for hourly analysis
* Creating **Month** information for monthly analysis
* Sorting and organizing transformed data
* Removing unnecessary or problematic records
* Preparing clean data for PivotTable analysis

This ensured that the dashboard was based on structured and analysis-ready data.

## 📈 Dashboard Features

### 1. Monthly Sales Analysis

The dashboard provides a monthly view of coffee sales performance.

This helps identify:

* Sales trends over time

### 2. Store Location Analysis

Sales can be analyzed based on different store locations.

This helps compare:

### 3. Hourly Sales Analysis

The dataset was analyzed by transaction hour to identify customer purchasing patterns.

## 🔍 Key Insights

| Area                         | Key Finding                                                                                                                |
| ---------------------------- | -------------------------------------------------------------------------------------------------------------------------- |
| ⏰ **Peak Sales Period**      | **10 AM** recorded the highest transaction quantity with **26,713 units sold**.                                            |
| ☕ **Top-Selling Product**    | **Ethiopia** was the top-selling product with **13,271 units sold**.                                                       |
| 📅 **Best-Performing Month** | **August** recorded the highest monthly quantity sold at **7,498 units**.                                                  |
| 📍 **Store Performance**     | **Lower Manhattan** led with **34%** of sales, while **Hell's Kitchen** and **Astoria** each contributed **33%**.          |
| 📦 **Product Category**      | **Coffee** was the dominant product category by quantity sold, followed by **Tea** and **Bakery**.                         |
| 📏 **Product Size**          | **Regular** was the most popular size at **33%**, followed by **Large (32%)**, **Not Defined (25%)**, and **Small (10%)**. |

### 📊 Overall Business Performance

* **214,470** total units sold
* **149,116** total transactions
* **$698,812.33** total revenue

### 💡 Business Takeaways

* Morning hours, particularly **10 AM**, represent a strong sales period and may require adequate staffing and inventory.
* **Ethiopia** is the strongest individual product and could be prioritized in product promotions and inventory planning.
* Sales are **well distributed across the three store locations**, with only a 1-percentage-point difference between the highest and lowest locations.
* **Coffee products dominate overall category demand**, highlighting coffee as the primary sales driver.

> The dashboard can be filtered using the slicers to explore these patterns at a more detailed level.
